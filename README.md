# recoco 記録アシスタント

訪問看護ステーションrecoco向けの記録下書きアプリです。
音声入力で羅列したメモを、AI（Google Gemini）が以下の文章に整形します。

- **訪問看護記録** → SOAP形式（S・O・A・P）
- **訪問看護計画書** → 目標・療養上の課題と支援内容・評価

整形した文章は欄ごとにコピーして、カイポケに貼り付けて使います。

## 使い方

1. **設定** 画面でGemini APIキーを登録（[Google AI Studio](https://aistudio.google.com/apikey) で無料取得）
2. ホームで「訪問看護記録を作る」or「訪問看護計画書を作る」を選択
3. メモ欄をタップし、スマホキーボードのマイクボタン🎤で話す（単語の羅列でOK）
4. 「AIで文章にする」→ 生成された文章を確認・手直し
5. 欄ごとの「コピー」ボタンでコピーし、カイポケに貼り付け
6. 「保存して履歴へ」で端末内に下書きを保存（あとから開いて再コピー・再編集可）

## 個人情報について

- 利用者名はアプリ（端末内）にだけ保存され、**AIには送信されません**
- メモには氏名・住所・電話番号を入れないでください（「Aさん」「本人」などでOK）
- 記録データはすべて端末内（ブラウザ）にのみ保存され、サーバーには残りません

## 開発

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に出力）
```

技術構成: Vite + React + TypeScript / Dexie (IndexedDB) / vite-plugin-pwa / Gemini API

## スマホで使うには（デプロイ）

`dist/` フォルダを静的ホスティング（Vercel・Netlify・GitHub Pages など）に公開し、
スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます。
（PWAのためHTTPSが必須。ローカルの `npm run dev` はPC確認用）
