# recoco 記録アシスタント

訪問看護ステーションrecoco向けの記録下書きアプリです。
音声入力で羅列したメモを、AI（Google Gemini）が以下の文章に整形します。

- **訪問看護記録** → SOAP形式（S・O・A・P）
- **訪問看護計画書** → 目標・療養上の課題と支援内容・評価

整形した文章は欄ごとにコピーして、カイポケに貼り付けて使います。

## 使い方

### 管理者（はじめに1回）

1. [Google AI Studio](https://aistudio.google.com/apikey) でAPIキーを取得する（無料枠）
2. アプリの **設定** →「管理者用（AIの設定）」を開く。初回は **管理者の暗証番号（4〜6桁）** を決める（職員には教えない）。キーを貼って「保存」→「接続テスト」
   - 保存したキーは画面に表示されません（「設定済み」とだけ出ます）。変えるときは新しいキーを貼って保存します
   - 職員のスマホにはQRで暗証番号（の照合用データ）も入るため、職員は管理者用の欄を開けません
   - 暗証番号を忘れたら、そのスマホのアプリのデータを消してから設定し直す（記録は先にバックアップを書き出しておく）
3. 同じ欄の **「職員用QRを作る」** を押し、出てきたQRコードを職員のスマホで読んでもらう
   - **QRコードにはキーが入っています。紙に印刷したり写真で送ったりせず、管理者の画面を直接読ませてください。**
   - カメラが使えない端末には「設定コードをコピー」で渡し、職員側で「コードを貼って設定する」に貼ってもらう
4. 暗証番号はキーを「普通の操作で見られないようにする」ための鍵で、スマホを詳しく調べる人までは防げません。
5. 職員が退職したときやQRが外に出たおそれがあるときは、AI Studioでキーを作り直し、全員にQRを読み直してもらう（設定 →「QRコードを読み直す」）

### 職員

1. ホームの **「はじめの設定をする」** を押し、管理者のQRコードを読む（「準備ができました」と出ればOK）
2. ホームの **「記録を書く」** → 名前のボタンを押す → メモ欄をタップしてマイク🎤で話す（体温や血圧もそのまま話せばOK）
3. **「文章にする」** を押す。「足りないところ」が出たら、その下の欄で話し足して「話し足して作り直す」
4. **「全部コピー（カイポケに貼る）」** を押し、カイポケの経過記録欄に貼る
5. **「確認して保存」** で端末内に保存（あとから「これまでの記録」で開いて再コピーできる）

## 個人情報について

- 利用者名はアプリ（端末内）にだけ保存され、**AIには送信されません**
- 氏名・住所・電話番号は話さないでください（「本人」などでOK）
- 無料枠のAIでは、送った内容がAIの改善に使われる場合があります
- 記録データはすべて端末内（ブラウザ）にのみ保存され、サーバーには残りません

## 開発

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に出力）
```

技術構成: Vite + React + TypeScript / Dexie (IndexedDB) / vite-plugin-pwa / Gemini API

## スマホで使う（公開URL）

GitHub Pages で公開済み。スマホのブラウザで下記を開き「ホーム画面に追加」するとアプリのように使えます。

**https://naraki03-sketch.github.io/recoco-kiroku/**

- iPhone(Safari): 共有ボタン → 「ホーム画面に追加」
- Android(Chrome): メニュー(⋮) → 「ホーム画面に追加」/「アプリをインストール」

### 更新方法（コードを直したとき）

```bash
git push            # ソースをGitHubへ
npm run deploy      # ビルドして gh-pages ブランチへ公開（数十秒で反映）
```

`npm run deploy` は `dist/` をビルドして gh-pages ブランチに上げる。GitHub Pages の配信元は
gh-pages ブランチ。`vite.config.ts` の `base: '/recoco-kiroku/'` はリポジトリ名に対応（独自ドメインや
Vercelに移す場合は `'/'` に戻す）。ローカルの `npm run dev` はPC確認用。
